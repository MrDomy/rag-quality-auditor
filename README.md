# RAG Quality Auditor

Цифровой сотрудник для анализа качества RAG-системы - сервис, который с помощью LLM оценивает ответ RAG-системы на вопрос пользователя и возвращает оценки в виде валидного JSON. Реализован на FastAPI, работает с любой LLM через OpenAI-совместимый API (по умолчанию - Gemini).

Ответ оценивается по трём метрикам от 1 до 5:

- `faithfulness` - подтверждаются ли утверждения ответа найденными чанками (выдумки снижают оценку, даже если верны в реальном мире);
- `answer_relevance` - отвечает ли ответ именно на заданный вопрос;
- `context_relevance` - содержат ли найденные чанки информацию, нужную для ответа.

Кроме оценок, сервис возвращает краткое обоснование (`reasoning`).

## Быстрый старт

Требуется Python 3.13 (проверено) и API-ключ провайдера LLM.

```bash
git clone <ссылка-на-репозиторий>
cd <папка-проекта>

python -m venv .venv
# Windows:        .venv\Scripts\activate
# Linux / macOS:  source .venv/bin/activate

pip install -r requirements.txt
```

Создайте файл `.env` на основе примера и впишите свой API-ключ:

```bash
cp .env.example .env        # Windows (cmd): copy .env.example .env
```

По умолчанию используется `gemini-2.5-flash` через OpenAI-совместимый эндпоинт Google. Чтобы подключить другого провайдера, измените `LLM_BASE_URL` и `LLM_MODEL` в `.env` (провайдер должен поддерживать структурированный вывод). Температура генерации задаётся константой `LLM_TEMPERATURE` в `main.py`.

Запустите сервер:

```bash
uvicorn main:app --reload
```

## Использование

Откройте Swagger UI: <http://127.0.0.1:8000/docs>. Нажмите на `POST /evaluate`, затем «Try it out», вставьте JSON и отправьте запрос прямо из браузера.

Пример запроса:

```json
{
  "question": "Какая столица Франции?",
  "chunks": ["Париж - столица и крупнейший город Франции."],
  "rag_answer": "Столица Франции - Париж, в нём живёт около 2 млн человек."
}
```

Пример ответа (значения и формулировки зависят от модели и могут отличаться между запусками):

```json
{
  "reasoning": "Утверждение о столице подтверждается чанком, но данных о численности населения в чанках нет, поэтому эта часть ответа не основана на контексте. Ответ по существу отвечает на вопрос, чанк подходит для ответа.",
  "faithfulness": 3,
  "answer_relevance": 5,
  "context_relevance": 5
}
```

Коды ответов:

| Код | Когда |
|---|---|
| `200` | Оценка получена |
| `422` | Некорректный запрос (например, пустые `question` или `rag_answer`, не тот тип данных) |
| `429` | Превышен лимит запросов к LLM-провайдеру (например, дневная квота бесплатного тарифа), повторите позже |
| `502` | LLM-провайдер недоступен, вернул ошибку или не вернул ответ в нужном формате. Подробности записываются в лог |
